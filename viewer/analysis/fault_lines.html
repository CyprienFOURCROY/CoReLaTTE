Fault Lines

Where CoReLaTTe's SQL-type benchmark models break: 91 MxFLS household-survey queries, each built around one of five deliberately injected structural biases, scored against three candidate models. Pick a model to see where its failures cluster.

By structural bias

Each v2 query is built to force one specific pattern in the generated pandas code — a post-aggregation filter, a comparison against a computed scalar, a multi-table join, a join with clashing non-key column names, or a join with a real row-fan-out risk. Sorted worst accuracy first.

By join width

Number of raw tables the query has to reason across at once.

By table involved

Accuracy across every query that touches a given MxFLS table (a query touching 3 tables counts once toward each of them).
